Hotel Vishaka Paark aims to make its website information clear, readable and usable across common devices.

Website accessibility

The website uses responsive layouts, clear navigation, readable typography, meaningful links, keyboard focus states and text alternatives for important images where appropriate.

Guest assistance

If you have accessibility-related requirements or need assistance with your stay, please contact the hotel before arrival so the team can discuss the arrangements that may be available.

Feedback

If you experience an accessibility problem while using the website, please contact Hotel Vishaka Paark directly so the issue can be reviewed.
